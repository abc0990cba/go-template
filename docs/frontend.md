# Frontend

The frontend is a server-rendered app with HTMX available for progressive enhancement.

Pages:

- `/register`
- `/login`
- `/`
- `/profile`
- `/users`
- `/enrichment`
- `/jobs`
- `/reports`
- `/analytics`
- `/docs`

The UI is a working dashboard, not a landing page. Every core backend capability should be testable from the browser.

The next UI OpenSpec change can replace the current `html/template` rendering with generated `templ` components.
